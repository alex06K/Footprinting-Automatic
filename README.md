🔍 Footprinting Automatisé – Bash Script

Ce projet est un script de footprinting automatisé écrit en Bash, conçu dans un cadre pédagogique pour la reconnaissance initiale (phase de footprinting) en cybersécurité.

Le script permet de collecter automatiquement des informations publiques sur une cible (domaine ou adresse IP) afin de mieux comprendre son exposition et son environnement technique.

⚙️ Fonctionnalités

Résolution DNS

Collecte d’informations WHOIS

Analyse des enregistrements DNS

Scan de ports non intrusif avec Nmap

Détection des technologies web utilisées

Export des résultats dans un fichier texte

🛠️ Outils utilisés

whois

nslookup

dig

nmap

whatweb

🎯 Objectif

Ce script a pour but de :

- Automatiser la phase de reconnaissance (footprinting)

- Mettre en pratique le Bash scripting

- Apprendre les bases de l’OSINT en cybersécurité

⚠️ Avertissement légal

Ce script doit être utilisé uniquement sur des cibles autorisées (labs, environnements de test, domaines personnels).
Toute utilisation non autorisée est interdit.
